    6. Column detection

    Se creó un ColumnDetector capaz de reconocer nombres de columnas en español e inglés.

    El diccionario contiene conceptos como:

    fecha
    ventas
    costos
    producto
    empleado
    area

    Ejemplos de aliases:

    fecha → fecha, date

    ventas → venta, ventas, sale, sales, total sales

    costos → costo, costos, cost, costs, total costs

    producto → producto, product

    empleado → empleado, employee, vendedor, salesperson

    area → área, area

    El detector normaliza:

        mayúsculas/minúsculas;

        acentos;

        _;

        -;

        espacios repetidos.

    Ejemplos:

    TOTAL_SALES → ventas
    total-costs → costos
    Área → area
    Empleado → empleado
    sales → ventas

    También maneja columnas desconocidas y columnas cuyo nombre no es str.

    10. Importante: cómo resolvimos el último fallo

    Inicialmente el pipeline creaba:

    Validator()

    Pero Validator() tenía:

    numeric_columns=()

    Por lo tanto este test fallaba:

    def test_pipeline_reports_validation_errors():
        dataframe = pd.DataFrame(
            {
                "sales": ["notnumeric"],
                "costs": [50],
            }
        )

        result = PreprocessingPipeline().process(dataframe)

        assert result.valid is False

    El problema era que no se estaba indicando al validator que sales y costs eran columnas numéricas.

    La solución actual fue configurar el pipeline así:

    self._validator = validator or Validator(
        numeric_columns=("sales", "costs", "ventas", "costos"),
    )

    Con eso:

    "sales": ["notnumeric"]

    genera un error de validación y el pipeline queda:

    result.valid is False

    Después de este cambio:

    69 passed
