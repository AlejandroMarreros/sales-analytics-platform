    4. IMPORTANTE: SHELL FISH

    El proyecto se está trabajando con Fish, no Bash.

    Por eso algunos comandos de Bash no funcionan directamente.

    Por ejemplo:

    cat > archivo <<'EOF'
    ...
    EOF

    produjo errores porque esa sintaxis heredoc pertenece a Bash y no debe asumirse compatible con Fish.

    Para crear archivos de varias líneas se utilizó correctamente printf.

    Esto debe tenerse en cuenta en futuras sesiones para no perder tiempo con comandos incompatibles con el shell.
