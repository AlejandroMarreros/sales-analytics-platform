7. ValidationResult

Archivo:

src/ml_platform/preprocessing/validation/result.py

Clase:

ValidationResult

Es un dataclass(frozen=True).

Contiene:

errors: tuple[str, ...]
warnings: tuple[str, ...]

La propiedad:

valid

devuelve:

not self.errors

Por tanto:

    sin errores → valid == True

    con errores → valid == False

    solamente warnings → valid == True

También convierte errors y warnings a tuplas para evitar exponer colecciones mutables.

Tests:

5 tests.

Estado:

✅ Pasando.
8. Reglas de validación implementadas

Archivo:

src/ml_platform/preprocessing/validation/rules.py
validate_dataframe_type

Comprueba que el valor recibido sea:

pandas.DataFrame

Si no:

TypeError
validate_dataframe_not_empty

Comprueba que el DataFrame no esté vacío.

Si está vacío:

ValueError
validate_unique_columns

Comprueba que no existan columnas duplicadas.

Si existen:

ValueError
validate_missing_values

Cuenta valores faltantes utilizando:

dataframe.isna().sum().sum()

Los valores faltantes actualmente se consideran:

warnings

No invalidan por sí solos el DataFrame.

Ejemplo conceptual:

Se encontraron 1 valores faltantes

validate_required_columns

Recibe:

required_columns: tuple[str, ...]

Detecta columnas obligatorias ausentes.

Devuelve mensajes de error.
validate_numeric_columns

Recibe:

numeric_columns: tuple[str, ...]

Utiliza:

pd.to_numeric(..., errors="coerce")

para detectar valores que no pueden convertirse a número.

Las columnas que no existen se ignoran actualmente.

Los valores no numéricos encontrados producen errores.

Validator
