1. Objetivo general

Estamos construyendo una plataforma modular de análisis de ventas, rentabilidad y Machine Learning con Python, integrada posteriormente con Power BI.

La plataforma tendrá como objetivo analizar:

    Ventas.

    Costos.

    Ganancias/utilidad.

    Margen de rentabilidad.

    Evolución de las ventas durante los últimos meses.

    Desempeño de áreas o sectores.

    Desempeño del personal.

    Productos.

    Tendencias.

    Detección de disminuciones o problemas de rentabilidad.

    Predicciones mediante Machine Learning.

La idea principal es:

8. Archivos de ingestion que ya empezamos

Ya creamos la idea de:

con una clase base:

class BaseReader(ABC):
    @abstractmethod
    def read(self, file_path: Path) -> Any:
        raise NotImplementedError

También:

src/ml_platform/ingestion/csv_reader.py

con:

class CSVReader(BaseReader):

y:

src/ml_platform/ingestion/excel_reader.py

con:

class ExcelReader(BaseReader):

Estos lectores validan:

    que el archivo exista;

    que tenga la extensión correcta;

    y luego utilizan pandas para cargarlo.

9. Lo siguiente que falta en ingestion

El próximo paso que habíamos definido es:

reader_factory.py

La idea es que el usuario no tenga que decirle al sistema:

    “Esto es un Excel, usa ExcelReader”.

El sistema detectará automáticamente:

ventas.csv
    ↓
CSVReader

ventas.xlsx
    ↓
ExcelReader

datos.json
    ↓
JSONReader

Es decir:

                  ARCHIVO
                     ↓
              ReaderFactory
                     ↓
        ┌────────────┼────────────┐
        ▼            ▼            ▼
      CSV          Excel         JSON
        ↓            ↓            ↓
    CSVReader    ExcelReader   JSONReader
