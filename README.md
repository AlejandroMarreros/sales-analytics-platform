# sales-analytics-platform

Plataforma modular en **Python** para **ingestión, validación, normalización,
limpieza y análisis de datos de ventas** desde CSV, Excel, JSON, PDF y TXT.
Soporte nativo **español/inglés**. Salida para **Power BI** y **Machine Learning**.
